# Cargo tools to preinstall in the runner's configured shared CARGO_HOME/bin.
# Offline jobs cannot `cargo install`; list required tools here and install
# them with install-tools.sh before admitting jobs.
#
# One tool per line:
#   <crate> <version>
#   <crate> git=<url> rev=<full sha> [default]
# A git tool is installed once per revision, because repositories pin different
# revisions and their outputs differ between them. Each binary is reachable as
# <bin>-<first 8 hex of rev>; the line marked `default` also owns the plain
# <bin> name. Mark at most one line per crate as default.
#
# Optional prerequisites not managed here (OS packages or non-Cargo installs):
# - wasm-opt: binaryen, for repositories that build WebAssembly.
# - x86_64-w64-mingw32-gcc/g++: gcc-mingw-w64-x86-64 and g++-mingw-w64-x86-64
#   with win32 threads, so crates with bundled C code (rusqlite, ring)
#   can be checked for x86_64-pc-windows-gnu.
# - sccache 0.18.0, patched: built by script/runner/build-sccache.sh from the
#   crates.io source plus patches/sccache-0.18.0-read-only-hits.patch. Stock
#   0.18.0 refreshes an entry's file times before every read, so readers of the
#   shared compile cache need the patch for read-only mounts. The runner uses
#   it for isolated read-only readers and the separate motor-cache writer.
#   It is not in the Cargo list below: cargo install would replace it with stock.
# - libsqlite3-dev: the system SQLite library and headers, for crates that link
#   SQLite instead of bundling it on Linux.
# - hivexregedit: libwin-hivex-perl 1.3.24 (not libhivex-bin, which ships only
#   hivexsh, hivexget and hivexml). Operator-only: the Windows no-persistence
#   qualification writes a registry canary into a job overlay's SOFTWARE hive.
# - Firecracker and its jailer, official 1.17.0 x86_64 release (tarball checked
#   against its published .sha256.txt), installed root-owned 0755 in
#   /usr/local/lib/firecracker/1.17.0/ with links /usr/local/bin/firecracker-1.17.0
#   and /usr/local/bin/jailer-1.17.0. Operator-only: the microVM and tenant-VM
#   work runs them as root on the host; jobs never start VMs.
# - flex, bison, libelf-dev and gcc-13 (13.4.0): kernel build prerequisites for
#   the operator's tenant-VM guest kernel (script/tenant-vm-spike/build-kernel.sh).
#   The host's default GCC 15 defaults to C23 and can't build the pinned Linux
#   6.1.128, so that kernel builds with gcc-13.
# - Node, pnpm and Bun: preinstall the versions required by repository manifests.
#   The runner also uses Bun for pre-job bun.lock installs. Verify official
#   release archives against published SHA-256 sums. Install tools under /usr
#   so the job sandbox can see them; its root does not bind /opt.
# - Rust targets: preinstall required targets through rustup for each required
#   toolchain. Examples include x86_64-unknown-linux-gnu, x86_64-pc-windows-gnu,
#   x86_64-pc-windows-msvc, aarch64-pc-windows-msvc, wasm32-unknown-unknown,
#   wasm32-wasip1 and x86_64-unknown-linux-musl (the microVM loader ships as a
#   static musl binary). Jobs see the rustup home read-only and cannot add targets.
# - Pinned Rust toolchains, through `rustup toolchain install <version> --profile
#   minimal --component clippy --component rustfmt`. The same read-only rule
#   applies: preinstall every toolchain required by a repository's pins.
